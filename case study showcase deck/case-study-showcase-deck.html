DESIGN STRATEGY

Three rules shaped every design decision.

01 · STATE

Expose state before detail.

Show what matters now. Keep logs one layer deeper.

02 · CONTROL

Intervention belongs in the workflow.

Pause, edit plan, review change and retry should feel native.

03 · EVIDENCE

Every result needs proof.

Connect output to tests, diffs or observable evidence.

REFLECTION

What this project changed in how I design AI products.

01 · FROM UI TO STATE

The interface is only the visible edge of an agent state machine.

02 · FROM FLOW TO RECOVERY

A trustworthy AI experience is defined as much by recovery as by the happy path.

03 · FROM COMPONENTS TO RULES

Reusable design knowledge should encode when and why—not just what a component looks like.
