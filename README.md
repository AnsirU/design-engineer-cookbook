# Design Engineer Cookbook

A growing cookbook of reusable design-engineering methods, research skills, and worked examples.

## Contents

- `competitive-analysis/` — competitive research workflow, reusable skill assets, and report examples.
- `ai-native design system skeleton/` — a brand-neutral skeleton for rapidly building an Agent-operable design system: architecture, design philosophy, component inventory, code structure, agent interface, templates, QA, and starter manifests.
