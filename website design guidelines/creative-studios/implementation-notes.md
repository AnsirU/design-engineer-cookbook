# Creative Studio Specimen Notes

The four first specimens are deliberately different:

- **Studio Freight** — brutal, editorial, almost print-like; use when you want intellectual tension and high-impact restraint.
- **PORTO ROCHA** — dense cultural/editorial system; use when you need a portfolio or report to feel designed without becoming decorative.
- **DIA** — kinetic typography and temporal identity; use when motion itself should carry brand meaning.
- **Locomotive** — immersive, cinematic and technical; use when interaction quality needs to demonstrate craft.

Do not combine all four at once. For a real project, select one primary reference and at most one secondary reference, then filter both through the target product's existing design DNA.
