# Competitive Analysis

Reusable competitive-analysis assets for product, UX, interaction, and AI-product research.

## Structure

- `skill/` — the reusable `competitive-analysis-research` skill and its supporting references/assets.
- `examples/` — worked HTML reports produced with the skill.

## Current skill

`competitive-analysis-research` v2.0 follows a research-first workflow: clarify the research question, discover an appropriate domain framework, build and confirm the competitor set, collect evidence, synthesize cross-product findings, and deliver a local HTML report.

## Examples

The v42 SparkAgent competitive-analysis report is the current reference example and belongs under `examples/`.
