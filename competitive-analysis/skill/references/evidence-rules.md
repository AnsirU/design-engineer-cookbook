# Evidence & Visual Rules

## 来源优先级

1. 官方 Docs / 官方页面 / Changelog
2. 用户当前截图
3. 官方帮助中心
4. 高质量第三方
5. 论坛
6. 推断

## 截图原则

一个重要结论必须有一张准确的图支持。

分析什么，图里就要出现什么。

不要：
- 用 landing page 证明复杂过程；
- 用 chat 证明 history；
- 同图反复证明完全不同的结论。

## 官方图优先

Docs 有合适截图时，优先用官方图。

如果用户提供更当前的产品截图，则当前截图优先。

## Logo

禁止自行近似重绘。

优先级：
1. 用户提供
2. 官方品牌资源
3. 官方站点资源
4. 已确认匹配的可信 icon package

绑定 Logo 时按产品 identity，不按数组顺序。

## 本地 HTML

关键资源：
- 用户截图
- Logo
- 关键 conclusion evidence

如果热链不稳定，应下载或内嵌。

普通 Docs 图片可以外链，但交付前必须检查。

## QA

必须检查：
- broken image
- 错产品 Logo
- 图文不符
- 重复截图
- debug text
- 外链权限弹窗是否影响阅读
