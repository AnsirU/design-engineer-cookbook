# Pre-delivery Checklist

## 研究
- [ ] 已判断模糊 / 明确需求
- [ ] 已定义研究目标
- [ ] 已搜索当前品类成熟框架
- [ ] 已给候选竞品让用户确认
- [ ] 核心 / 补充样本角色清楚

## 框架
- [ ] 框架匹配当前产品类型
- [ ] 没有强套 Agent 框架
- [ ] 同一个研究问题没有两套冲突维度
- [ ] 机制和 UI 呈现已区分

## 证据
- [ ] 核心结论都有匹配截图
- [ ] 优先用官方 / 当前证据
- [ ] 没有旧截图假装当前 UI
- [ ] 没有明显重复截图
- [ ] Logo 全部正确

## 报告
- [ ] 没有内部修改意见
- [ ] 没有“这一版 / 按要求 / 后续再”等生成语言
- [ ] 只有一套设计结论
- [ ] 没有优先级冲突
- [ ] 每个核心竞品有不同的研究价值
- [ ] 有下一步纵向 / 横向研究

## HTML
- [ ] 本地能直接打开
- [ ] 侧导 / 导航正常
- [ ] 图片可放大
- [ ] UI 图使用 contain
- [ ] 关键图和 Logo 不会失效
- [ ] 没有 debug comment
